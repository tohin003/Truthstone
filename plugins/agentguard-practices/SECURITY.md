# Security policy

## Scope

This plugin contains only Markdown instructions (skills), YAML display metadata, JSON manifests and image assets. It has no executable code, no hooks, no MCP servers and no network access.

A security issue in this plugin is an instruction that could lead an agent to cause harm, for example by:

- leaking a secret
- bypassing the platform's approval prompts
- running a destructive command without the user's consent

## Reporting a vulnerability

Report vulnerabilities privately, not in a public issue. Use GitHub's private vulnerability reporting for https://github.com/tohin003/AgentGuard: open the **Security** tab and select **Report a vulnerability**.

You can also contact the maintainers through the channels listed at https://github.com/tohin003/AgentGuard/blob/master/docs/legal/SUPPORT.md.

## Supported versions

Only the latest release receives fixes. Update to the newest version before you report a problem.
